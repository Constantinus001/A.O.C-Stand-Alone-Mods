# A.O.C. Stand-Alone Mods

Independent, source-available modules from the Ages of Calradia project.

## Modules

- [World Events Standalone](WorldEventsStandalone/README.md) — campaign chronicle, character story, realm affairs, war statistics, marriage, and strategic-map interface.

Each module directory contains its source project, complete Bannerlord module tree, and verification/build scripts. The integrated versions used by the full Ages of Calradia suite remain in the main Ages of Calradia repository.
